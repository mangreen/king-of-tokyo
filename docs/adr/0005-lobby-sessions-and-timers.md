# ADR-0005：大廳、身分重連與逾時代打（M2）

- 狀態：已採用（2026-11-07）

## 背景

使用者要求**不需註冊**、瀏覽器優先、朋友之間對戰（目標容量 10,000 人在線，見 ADR-0002）。M2 要讓 2–6 人能在瀏覽器裡建房、加入、打完整局，並且斷線可以回來。

## 決策

### 身分：暱稱 + 重連 token

- 握手時送暱稱（`NicknameSchema`）。伺服器產生 `playerId`（公開識別，8 bytes）與 `sessionToken`（32 bytes CSPRNG，64 位十六進位字元）。
- **token 等同密碼**：只回傳給該連線，伺服器只存 SHA-256 雜湊；不出現在其他玩家看到的訊息、日誌與畫面狀態。客戶端存在 `sessionStorage`（只在該分頁有效），重新整理頁面可接回，關分頁就失效。
- 重連：握手帶 `sessionToken` → 接回同一身分、同一座位（暱稱沿用原本的）。token 未知或過期視為新玩家（不回報「token 不存在」，避免被探測）。
- 同一身分在別處登入：舊連線收到 `session_replaced` 並被中斷。
- 斷線且不在任何房間的身分保留 10 分鐘；在房間內的身分跟著房間，房間關閉後才回收。
- **取捨：** 沒有帳號代表沒有「找回身分」的管道，token 遺失就是新玩家。這符合「私人與朋友遊玩、不註冊」的需求。

### 房間

- 房號 5 碼（去掉 I、O、0、1），以 `crypto.randomInt` 產生；房間數上限 `MAX_ROOMS`（預設 2000）。
- 流程：建立 → 加入（≤6 人）→ 非房主按「準備」→ 房主開始（≥2 人且全部已準備）。開始後不能加入。座位依加入順序分配；先手由規則引擎擲骰決定。
- 一位玩家同時只能在一個房間。房主離開時順位給下一位。對局中離開的座位由系統代打到結束。
- 沒有任何玩家在線超過 5 分鐘，房間關閉；對局結束後最多再保留 10 分鐘。
- 大廳階段離線超過 60 秒的成員會被移出（避免有人加入後離線，永遠佔位、擋住開局）；房主離開時交給在線的下一位。

### 訊息

- 客戶端只送意圖：`room:create/join/leave/ready/start`、`game:action`（擲骰保留的索引、結算、讓位）。**座位由伺服器依身分決定**，客戶端送的 `seat` 會被丟棄。
- 每則訊息用 zod 驗證，並以 Socket.IO ack 回傳 `{ok:true}` 或穩定的錯誤碼（規則引擎的拒絕原因原樣回傳）。
- 伺服器推送：`room:state`（大廳／房間快照）與 `game:update`（版本、狀態、本次事件、剩餘毫秒、輪到誰）。`game:update` 帶 `version`，客戶端丟棄過期的；重連時重送完整狀態且 `events` 為空（不重播動畫）。
- 協定版本升為 2。

### 計時與代打

| 情況                   | 等待時間      |
| ---------------------- | ------------- |
| 在線玩家擲骰／結算     | 45 秒         |
| 在線玩家決定是否讓位   | 20 秒         |
| 已被標為代打、但仍在線 | 每一步 8 秒   |
| 斷線或已離開           | 每一步 1.5 秒 |

**時鐘不能被重連拖延：** 斷線只會「縮短」輪到他時的等待（到 1.5 秒），重連**不會**重設或延長時鐘；同一身分換連線（取代舊連線）時，先綁定新連線再踢舊的，因此其他玩家不會看到「離線」閃動，也不會動到計時。

逾時就由伺服器以「固定策略機器人」代打一步並把玩家標為 `away`；玩家再做出任何合法操作就解除。代打的動作也記進動作日誌，因此「seed + 動作日誌」仍可完整重放（M5 事件日誌用）。計時全部經 `Scheduler` 抽象，測試用假時鐘，不靠真實等待。

### 濫用防護

- 單則訊息大小上限（沿用 M0）、握手逾時、Origin 檢查（沿用 M0）。
- 新增：每連線 token bucket（突發 30、每秒補 5），超過回 `rate_limited`；房間數上限。
- **已知缺口（M5 處理）：** 握手本身沒有限流、沒有每個 IP 的連線與建房限制。反覆建立連線可以累積閒置身分（各保留 10 分鐘），大量建房可以佔滿 `MAX_ROOMS`；房號（約 3,300 萬種）也能被探測。單機私人遊玩可接受，公開上線前必須補上。
- **尚未做（M5）：** 每個 IP 的連線數與建房頻率限制、依 IP 的限流（需要反向代理資訊）。

## 影響

- `@kot/protocol` 以「僅型別」的方式引用 `@kot/rules`（`GameState`、`GameEvent`），沒有執行期依賴。
- `buildUpdate` 已預留「依觀看者過濾」的位置；M3 加入牌堆後在此遮蔽隱藏資訊。
- 單一實例、記憶體房間的限制不變（ADR-0002）；伺服器重啟會中斷進行中的對局。
