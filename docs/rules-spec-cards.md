# 能力卡規則（R-CARD）

- 狀態：**M3 草案 → 實作中**（2026-11-07）。規則來源：官方規則書（專案文件 `king-of-tokyo_rules.txt` 的 Glossary 與 Special cards overview）＋ 使用者提供卡表的卡面文字。
- 本文件補充 [rules-spec.md](rules-spec.md) 的 §2.6。卡牌**資料**與**效果**分離（[ADR-0004](adr/0004-swappable-card-sets.md)、[ADR-0006](adr/0006-card-engine.md)）：以下規則描述引擎行為，與卡牌組內容無關；卡面詞句只用通用說法，不引用任何特定卡組。
- 官方規則沒有明說、需要我們做決定的地方標為「**詮釋**」，並收在文末的 OQ-C 清單，請使用者確認或推翻。

## 1. 牌庫與商店

| 編號      | 規則                                                                                                                         |
| --------- | ---------------------------------------------------------------------------------------------------------------------------- |
| R-CARD-10 | 開局把卡牌組洗成牌庫（用遊戲 RNG），翻開 3 張面朝上。沒有卡牌組（空目錄）時遊戲不含卡牌，行為與 M1 相同。                    |
| R-CARD-11 | 買走一張面朝上的卡後，立刻從牌庫頂補一張。牌庫空了就把棄牌堆洗回牌庫（**詮釋** OQ-C1）；兩者都空就不補。                     |
| R-CARD-12 | 掃牌：花 2 能量，把 3 張面朝上的卡全部棄掉並翻出 3 張新牌。買牌與掃牌可任意順序，直到不想再做。                              |
| R-CARD-13 | 買牌只在自己回合的「買牌階段」，位於進入東京之後、回合結束之前（R-CARD-20）。                                                 |
| R-CARD-14 | 費用 = 卡面費用 − 所有費用減免，最低 0。能量不足不能買。                                                                     |
| R-CARD-15 | Keep 卡放在買家面前直到被棄掉；Discard 卡買下後立即結算並進棄牌堆。兩者買下時都會觸發「買牌」類效果。                         |
| R-CARD-16 | 怪獸被淘汰時，所有 Keep 卡進棄牌堆（R-SMASH-04）。Poison／Shrink 指示物留在原處，不受卡牌離場影響。                           |

## 2. 回合流程（有卡牌時）

| 編號      | 規則                                                                                                                                                                                                                                                                        |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R-CARD-20 | 回合：回合開始效果 → 擲骰 → 結算（VP→能量→治療→攻擊）→ 讓位 → 進入東京 → **買牌** → 回合結束效果 → 勝負判定 → 下一位。                                                                                                                                                  |
| R-CARD-21 | 骰子數 = 基礎 + 加骰卡 − Shrink 指示物數 − 雷霆踏步（見 R-CARD-63）− 額外回合減骰；最少 1 顆。擲骰次數 = 基礎 + 加擲卡。這兩個數字在回合開始時決定。                                                                                                                       |
| R-CARD-22 | 擲骰次數用完後，若持有者還有可用的擲骰期能力（改骰、額外重擲、只重擲 3 的卡），就**不會**自動結算，必須按「結束擲骰」。沒有任何可用能力時維持 M1 的自動結算。                                                                                                              |
| R-CARD-23 | 「改骰」類能力（任意面、改成 1 等）在已擲過至少一次、尚未結算時使用，直接改寫骰面；「額外重擲」使本回合可擲次數 +1。                                                                                                                                                       |
| R-CARD-24 | 「隨時」類能力（花能量補血、花能量換 VP）：在自己回合的擲骰階段與買牌階段可用；被詢問決定時（讓位、反應）也可用。不能在別人回合的任意時刻插入（**詮釋** OQ-C2）。                                                                                                       |

## 3. 攻擊與傷害

| 編號      | 規則                                                                                                                                                                                                                                                  |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R-CARD-30 | 「攻擊」只指骰面的攻擊（官方 Glossary）。Discard 卡造成的傷害、額外傷害（如鄰座傷害）、毒傷、反射傷害都**不是攻擊**：不能讓位、不吃「攻擊時」加成。                                                                                                  |
| R-CARD-31 | 加傷卡只在有攻擊時才加，不會把 0 變成 1；唯一例外是卡面明寫「沒有攻擊也造成」的卡（每回合固定傷害）。                                                                                                                                                 |
| R-CARD-32 | 每個目標的傷害 = 攻擊傷害 + 對東京加傷（若該目標在東京）。再加鄰座額外傷害：攻擊者左右鄰座（存活者）各 +1，即使不是目標也受傷。同一目標的所有傷害合成一筆。                                                                                          |
| R-CARD-33 | 目標減傷順序：忽略 1 點傷害（只在該筆傷害剛好為 1 時）→ **反應詢問**（R-CARD-34）→ 迷彩擲骰（每點傷害擲一顆，出現治療面就免除該點）→ 扣血。                                                                                                          |
| R-CARD-34 | 反應詢問：目標若持有可用的「花能量減傷」（整回合免傷、免 1 點傷害）或「讓位免傷」能力，在扣血前被詢問；可連續使用多個，按「不使用」結束。**只針對骰面攻擊**；Discard 卡的傷害不詢問，但已啟動的整回合免傷仍有效（**詮釋** OQ-C3）。                          |
| R-CARD-35 | 免傷讓位：持有「讓位免傷」能力且在東京內的怪獸，可在被傷害前直接讓位、不受這次攻擊的傷害；攻擊者仍然進入東京（官方 Glossary）。                                                                                                                       |
| R-CARD-36 | 扣血後觸發：受傷 ≥ 門檻得能量、反射傷害（不可再被反射）、攻擊者的指示物與回血。HP 歸零進入 R-CARD-40。                                                                                                                                               |
| R-CARD-37 | 強制讓位：攻擊者持有強制讓位卡時，被他實際傷到的東京內怪獸自動讓位（不詢問）。                                                                                                                                                                       |
| R-CARD-38 | 讓位時觸發：離開者的「讓位傷害」卡對進入者造成傷害；離開者的「讓位換卡」卡可從接手者拿一張 Keep 卡並把本卡換給他。                                                                                                                                    |
| R-CARD-39 | 回合結束時，帶有毒指示物的怪獸受到「指示物數」點傷害（來源不明，不是攻擊，不觸發反射或搭檔）。                                                                                                                                                       |

## 4. 淘汰、復活與搭檔

| 編號      | 規則                                                                                                                                                                                                                  |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R-CARD-40 | HP 歸零時依序檢查：持有「復活」卡 → 棄掉所有卡、VP 歸零、HP 設為卡面數值（≤ 最大值）、離開東京、繼續遊戲；持有「搭檔」卡（且尚未用過）且有明確的擊殺者 → HP 設為卡面數值、VP 歸零、與擊殺者結為搭檔；否則淘汰。 |
| R-CARD-41 | 「HP 歸零」本身觸發「有怪獸 HP 歸零」類效果（吃屍者），即使因復活而沒有淘汰。                                                                                                                                         |
| R-CARD-42 | 搭檔：擊殺者被淘汰時，搭檔一併淘汰；任一方勝利、或剩下的存活者只有兩人時，兩人**共同勝利**（OQ-4）。搭檔第二次被淘汰時卡牌無效。自傷、毒傷、無來源傷害沒有擊殺者，搭檔卡不生效。                                       |
| R-CARD-43 | 被骰面攻擊淘汰的東京怪獸，攻擊者會接手東京；被卡牌或毒淘汰則東京空出（官方規則）。                                                                                                                                    |

## 5. 買牌階段能力

| 編號      | 規則                                                                                                                                                                       |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R-CARD-50 | 向他人買牌：持有此能力者可購買其他怪獸的 Keep 卡，把費用付給對方；卡上的計數隨卡轉移。                                                                                     |
| R-CARD-51 | 窺牌買牌：可偷看牌庫頂一張（只有使用者看得到，伺服器對其他人隱藏），並以一般費用購買它。                                                                                   |
| R-CARD-52 | 新牌即買：每當有新牌翻開，持有此能力的**其他**怪獸依「從當前回合怪獸起順時針」的順序，各有一次機會立即購買該牌；買下後又翻出的新牌同樣給機會。                              |
| R-CARD-53 | 回合結束出售：在買牌階段結束前可把任意張 Keep 卡賣回，每張得到**卡面費用**（不受減免影響）。                                                                               |
| R-CARD-54 | 複製：買下時選一張場上任何怪獸持有的 Keep 卡，視同剛買下該卡（包含買下時效果）。複製的目標離場時指示物收回，可在自己回合開始（擲骰前）付 1 能量重新指定。不可複製複製卡。 |
| R-CARD-55 | 電池：買下時從自己能量中放上指定數量（≥0）；每個自己回合開始時取下 2 能量進自己的庫存；取完就棄掉。                                                                         |
| R-CARD-56 | 額外回合（Frenzy 類或連三個 1 的卡）：本回合結算完所有效果、通過勝負判定後，同一位怪獸立刻再開一個回合（R-END-09）。可以疊加，但每次只在上一個回合結束時才生效。          |

## 6. 心與指示物

| 編號      | 規則                                                                                                                                                                                                              |
| --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R-CARD-60 | 結算治療面時，若持有者有可分配的選項（可移除自己的指示物，或持有「替他人治療」卡且有合格對象），改為詢問分配；否則直接治療。在東京內治療面無效，但仍可用來移除指示物。**詮釋**：在東京內不能移除指示物（官方說明：必須取代治療，所以在東京內不行）。 |
| R-CARD-61 | 移除指示物只能在東京外，每顆耗用 1 顆治療面（不回血）。                                                                                                                                                              |
| R-CARD-62 | 替他人治療：每回 1 點，被治療者付 2 能量給持有者（不足就付全部剩下的）；對象須存活、受傷且有至少 1 能量。（**詮釋** OQ-C4：東京內的對象也可被治療。）                                                              |
| R-CARD-63 | 「全場少擲一顆」效果：持有者回合結束時若該回合得到 ≥ 門檻 VP，所有怪獸（含自己）骰子數 −1，直到持有者下一個回合開始。多張效果疊加。                                                                                |

## 7. 同時間的效果順序

回合開始：東京 +2 VP → 回合開始類效果（持有順序）。回合結束：先出售（R-CARD-53，屬於買牌階段）→ 毒傷 → 持有者的回合結束效果（按持有順序）→ 所有怪獸的「任一回合結束」效果（按座位）。持有順序 = 買下的順序。

## 8. 待確認（OQ-C）

| 編號  | 問題                                                                           | 暫定                                                              |
| ----- | ------------------------------------------------------------------------------ | ----------------------------------------------------------------- |
| OQ-C1 | 牌庫用完是否把棄牌堆洗回                                                       | 洗回（官方規則書未寫）                                            |
| OQ-C2 | 「隨時」能力能否在別人回合任意時點使用                                         | 否；只在自己回合或被詢問時（回合制伺服器的合理簡化）              |
| OQ-C3 | Discard 卡造成的傷害是否詢問減傷反應                                           | 否（只詢問骰面攻擊）                                              |
| OQ-C4 | 替他人治療能否治療東京內的怪獸                                                 | 可以                                                              |
| OQ-C5 | 「得到 N VP 的回合」「造成 N 點傷害的回合」類門檻怎麼算                        | VP 含所有來源；傷害為本回合實際造成的總傷害（扣除減傷後）         |
| OQ-C6 | 「每回合固定加傷」是否算攻擊（能讓位）                                         | 算；因為它讓這次骰面結算成為攻擊                                  |
| OQ-C7 | 損失 Even Bigger 類最大 HP 卡時，現有 HP 如何處理                              | 只把 HP 夾到新上限，不額外扣                                      |
| OQ-C8 | 「得到能量時額外得到」是否包含轉移與出售所得                                   | 不包含（轉移、出售、電池取回都不算「得到」）                      |
| OQ-C9 | 搭檔與復活同時持有時的優先順序                                                 | 先復活、後搭檔                                                    |
